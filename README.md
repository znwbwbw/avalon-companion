# AVALON — 대면 게임 진행 보조 앱

5~10명이 각자 휴대폰 브라우저로 입장해, 오프라인 토론을 진행하면서 역할·원정·투표·결과를 처리하는 웹앱입니다.

## 시작하기

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

실행 후 서버 컴퓨터에서 `http://localhost:3000` 접속. **같은 Wi-Fi의 다른 휴대폰**에서는 서버 PC의 내부 IP를 사용해 `http://192.168.x.x:3000`으로 접속하세요. PC 방화벽에서 포트 3000을 허용해야 할 수 있습니다.

인터넷을 통한 접속은 Node.js WebSocket 업그레이드를 지원하는 호스팅에 배포하고 HTTPS/WSS를 구성하세요. 서버가 종료되면 메모리에 저장된 게임도 사라집니다.

## 지원 기능

- 방 코드 5자리 생성, 링크 공유, 5~10인 입장, 방장 직업 옵션 설정
- 멀린·암살자 필수, 퍼시벌·모르가나·모드레드·오베론 옵션
- 각 역할별 비밀 정보 서버 측 분리 및 개인별 확인
- 원정 리더 자동 순환, 인원수별 원정 정원 자동 적용
- 전원 찬반 투표, 과반 찬성 승인, 연속 5회 부결 시 악 승리
- 비밀 원정 투표, 선 진영 실패표 선택 불가, 7~10인 4차 원정 2실패 규칙
- 선 3성공 시 암살, 악 3실패 시 승리, 게임 종료 후 역할 공개
- 동일 브라우저 재접속, 모바일 UI, 같은 멤버로 재시작

## 주요 주의사항

- **1차 실행형 MVP**입니다. 서버 메모리 기반이므로 운영 서버 재시작 시 데이터가 초기화됩니다.
- 기기별 방 참가 인증은 브라우저의 로컬 토큰에 기반합니다. 공개 서비스용으로 배포할 경우 인증/권한, 토큰 갱신, rate limit, DB 영속화, 안전한 서버 로깅 및 부하 검증을 추가하세요.
- 악 진영의 특수 역할 구성 수가 해당 인원에서 가능한 악 진영 수보다 많으면 시작이 거부됩니다.
- 원작 게임의 상표·카드 일러스트를 포함하지 않은 독자적인 보조 UI입니다.
- 실제 플레이에서 초기 정보 전달과 토론은 참가자가 현장에서 수행합니다. 앱에서 각자의 역할을 확인한 뒤 직접 토론하세요.


## v1.1 개선 사항
- 연결 상태를 상단에 표시하고 네트워크 중단 시 자동 재연결합니다.
- 찬반 및 원정 성공/실패 투표 제출 전에 확인창을 표시합니다.
- 원정 결과 화면의 다음 원정 진행은 방장에게만 허용합니다.
- 진행 중 공개 데이터에서 암살자 식별 ID를 제거해 비밀 역할 노출을 방지합니다.
- 모바일 작은 화면에서 버튼 및 간격을 조정하고 링크 공유 실패 시 복사 대안을 표시합니다.
- 서버 데이터는 여전히 메모리 저장이며 서버 재시작 시 초기화됩니다.

- 모바일 대비, 카드/타이포/버튼 디자인 및 작은 화면 대응 개선, 홈 화면 아이콘과 웹앱 manifest 추가

- `/health` 엔드포인트, `render.yaml`, `.gitignore`, `DEPLOY_RENDER.md` 추가
- 기존 게임 규칙·투표 프로토콜은 변경하지 않았습니다.
- **웹 주소 배포는 아직 수행하지 않았습니다.** 외부 호스팅 연결과 실제 기기 테스트가 별도로 필요합니다.


## v1.3: 숫자 코드 및 QR 입장
- 방 코드는 숫자 4자리(앞자리 0 허용)입니다. 이전 버전에서 만든 영문 코드는 사용할 수 없습니다.
- 대기실에서 QR 코드를 스캔하면 방 번호가 자동 입력된 참가 화면으로 이동합니다. 참가자는 닉네임을 적고 '기존 방 참가하기'를 누릅니다.
- VS Code PC에서 localhost로 접속했다면 초대 주소에서 PC의 Wi-Fi/LAN IP를 고르세요. 휴대폰도 동일 네트워크에 연결되어야 합니다. 방화벽이 3000 포트를 차단하면 접속할 수 없습니다.
- QR은 서버에서 로컬 생성되므로 외부 QR 코드 제공 사이트를 사용하지 않습니다.

## v1.4 변경 사항
- 게임 방 코드를 숫자 4자리(0000~9999)로 변경했습니다.
- QR 초대 링크도 숫자 4자리 방 코드를 사용합니다.
- 서버 재시작 시 기존 대기실은 사라지며, 동일한 4자리 코드는 동시에 중복 발급되지 않습니다.


## v1.5 — 원탁 좌석 시스템
- 이미지 파일 `public/avalon-table.png`은 상판 배경 전용입니다. 좌석은 HTML 버튼으로 분리했습니다.
- 4자리 숫자 코드 및 QR 입장 유지. 대기실에서 각자 빈 좌석을 누르고 준비 완료를 누릅니다.
- 5~10명 전원이 착석하고 준비 완료해야 방장이 시작할 수 있습니다.
- 좌석 변경 시 준비 완료 취소. 게임이 시작되면 좌석 순서 고정, 최초 리더는 무작위, 이후 리더는 좌석 번호 순서로 이동합니다.
- 원정 리더는 테이블 바깥 참가자 좌석을 터치해서 원정팀을 선정하며 선택 시 금색 테두리가 나타납니다. 찬반 투표는 테이블 중앙에서 수행합니다.
- 서버는 아직 방 정보를 메모리에 저장합니다. 배포 전 실기기 테스트가 필요합니다.
